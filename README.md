This project implements a computationally efficient Recurrent Neural Network (RNN) for short-term maritime trajectory prediction. By discretizing spatial data into a navigable grid and utilizing a minimalistic Sequence-to-One LSTM architecture, the model achieves high predictive accuracy while remaining extremely lightweight (<50 kB). Designed specifically for embedded inference, this approach balances performance with the strict memory and energy constraints of edge devices.

This work was completed as part of the Deep Learning course at Danmarks Tekniske Universitet.
